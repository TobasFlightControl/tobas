# Release v2.12

## Changes

---

### Missions

- Added support for specifying default values for mission parameters
- Added support for overriding default parameters on the mission planning screen
- RTL now executes through Land
- New missions can interrupt an active mission based on priority
- Missions cannot be executed while manual mode is enabled

### Ground Station

- Changed the map from OSM to aerial imagery
- Added map overzoom support
