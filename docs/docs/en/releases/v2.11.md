# Release v2.11

## Operating Environment

---

ROS 2 Jazzy

## Changes

---

### State Estimation

- Takeoff is detected using only ground reaction force, as acceleration and velocity are prone to false detection

### Control

- Integral errors are reset upon disarming rather than when landing is detected
- Implemented rate mode for Y-axis tilt multirotors

### Missions

- Consolidated the action servers for mission execution into a single node
- All mission commands are sent to the FC before execution
- Run Mission Executor as a Component
- The Land command carries over the previous target latitude and longitude

### Manual Mode

- Use `vehicle_health` as the criterion for determining whether mode changes are allowed

### Flight Logs

- Implemented CSV export for flight logs

### Other

- Implemented an action interface in `tobas_ros_interface`
- Added a remote IF for `external_pose`
