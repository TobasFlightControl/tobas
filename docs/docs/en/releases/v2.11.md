# Release v2.11

## **Environment**

---

ROS 2 Jazzy

## **Changes**

---

### **State Estimation**

- Changed takeoff detection to use only ground reaction force, since acceleration and velocity are prone to false detections

### **Control**

- Moved integral error reset from landing detection to disarming
- Added rate mode for multicopters with Y-axis tilt

### **Missions**

- Consolidated mission execution action servers into a single node
- Changed mission execution to send all mission commands to the FC before starting
- Changed Mission Executor to run as a component
- Changed the Land command to inherit the preceding target latitude and longitude

### **Manual Mode**

- Changed mode-switch eligibility checks to use `vehicle_health`

### **Flight Logs**

- Added CSV export for flight logs

### **Other**

- Added an action interface to `tobas_ros_interface`
- Added a remote interface for `external_pose`
