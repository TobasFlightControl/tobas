# Release v2.9

## Changes

---

### Control

- Automatically disarm when landing is detected

### Missions

- Improved path planning for waypoint flight

### Failsafe

- Added alignment with the geomagnetic reference vector to the checklist

### Manual Mode

- Reversed the throttle lever configuration to match Futaba
- Changed RC switch channels (CH5 is now used for flight mode)
- Reduced RPM at zero throttle

### Ground Station

- Improved the layout
- Added GNSS status display

### Flight Logs

- Added ESC communication error display
- Added CPU status display

### Simulation

- Added a Gazebo world
- Added GUI support for selecting the FTDI USB device

### Other

- Reduced messages output under `/rosout` and `~/.ros/log/`
- Added calculation and publishing of vibration levels from accelerometer readings
- Changed the world coordinate system from NWU to ENU
- Added Wi-Fi Key Management types
- Added the version to the GUI title
- Added Tobas project version checking

## Bug Fixes

---
