# Release v2.9

## **Environment**

---

ROS 2 Jazzy

## **Changes**

---

### **Control**

- Added automatic disarming when landing is detected

### **Missions**

- Improved path planning for waypoint flights

### **Fail-Safe**

- Added a check for alignment with the reference magnetic field vector

### **Manual Mode**

- Changed throttle input to assume a reversed stick, matching Futaba transmitters
- Changed RC switch channel assignments (CH5 is now the flight mode)
- Reduced motor speed at zero throttle

### **Ground Control Station**

- Improved the layout
- Added GNSS status display

### **Flight Logs**

- Added ESC communication error display
- Added CPU status display

### **Simulation**

- Added Gazebo worlds
- Added GUI selection of FTDI USB devices

### **Other**

- Reduced messages output to `/rosout` and files under `~/.ros/log/`
- Added calculation and publication of vibration levels from accelerometer readings
- Changed the world coordinate frame from NWU to ENU
- Added Wi-Fi key management types
- Added the version to GUI window titles
- Added Tobas project version checks

## **Bug Fixes**
