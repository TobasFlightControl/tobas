## Changes

---

### Sensor Processing

- Changed the compass calibration method from min-max to ellipsoid fitting

### Modeling

- Added support for estimating engine dynamics
- Added support for estimating the aerodynamic characteristics of variable-pitch propellers

### Control

- Added support for multicopters that tilt only about the Y-axis
- Improved the mixer for multicopters with non-coplanar rotor configurations
- Added support for configuring multicopter gains using either the standard second-order form or a two-stage cascade

### Communication

- Changed GCS-to-FC authentication from login passwords to SSH keys
- Fixed a bug that prevented ROS communication when restarting a simulation immediately after it ended

### Other

- Added tab color indicators for the completion of sensor calibrations
- Added support for directly editing configuration files on the boot device
- Added support for relative paths in UADF
- Added a remote interface for RC commands
