# Release v2.7

## **Environment**

---

ROS 2 Jazzy

## **Changes**

---

### **Sensor Processing**

- Changed compass calibration from the min/max method to ellipsoid fitting

### **Modeling**

- Added engine dynamics estimation
- Added aerodynamic parameter estimation for variable-pitch propellers

### **Control**

- Added support for multicopters that tilt only about the Y axis
- Improved the mixer for multicopters with noncoplanar rotors
- Added the option to configure multicopter gains using a two-stage cascade as well as the standard second-order form

### **Communication**

- Changed GCS-to-FC authentication from login passwords to SSH keys
- Fixed a ROS communication failure when restarting a simulation immediately after stopping it

### **Other**

- Added tab colors to indicate completion of each sensor calibration
- Added direct editing of configuration files on the boot device
- Added support for relative paths in UADF
- Added a remote interface for RC commands
