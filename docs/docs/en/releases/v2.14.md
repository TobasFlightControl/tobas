# Release v2.14

## Operating Environment

---

ROS 2 Jazzy

## Changes

---

### Sensor Processing

- Enabled BDU (Block Data Update) for IMU, Mag, and Baro

### Control

- Increased the system-wide operating frequency from 400 Hz to 800 Hz
- Changed the default damping ratio for horizontal position control from 1.0 to 0.7
- Added support for specifying the center pitch angle for engine-powered aircraft (default: 0 deg)

### Failsafe

- Added support for user-defined checks in the Pre-Arm Check

### Flight Logs

- Added PWM throttle
- Removed the 10 GB capacity limit

### Simulation

- Added simulation process monitoring

### Other

- Clear the cache when building local projects
- Smooth and publish CPU temperature and load
