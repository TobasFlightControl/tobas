# Release v2.14

## **Environment**

---

ROS 2 Jazzy

## **Changes**

---

### **Sensor Processing**

- Enabled BDU (Block Data Update) for the IMU, magnetometer, and barometer

### **Control**

- Increased the overall system operating frequency from 400 Hz to 800 Hz
- Changed the default horizontal position control damping ratio from 1.0 to 0.7
- Added a configurable pitch angle center for engine-powered aircraft (default: 0 deg)

### **Fail-Safe**

- Added user-defined items to the Pre-Arm Check

### **Flight Logs**

- Added PWM throttle
- Removed the 10 GB capacity limit

### **Simulation**

- Added simulation process monitoring

### **Other**

- Added cache clearing when building local projects
- Smoothed CPU temperature and load readings before publishing
