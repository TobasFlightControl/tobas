# Release v2.10

## **Environment**

---

ROS 2 Jazzy

## **Changes**

---

### **State Estimation**

- Added sensor selection for the ESKF in Setup Assistant
- Added external pose input to the ESKF
- Changed the conditions for takeoff and landing detection

### **Fail-Safe**

- Made the ESC communication loss threshold configurable
- Once target thrust is being generated, disarm after 500 ms of communication loss instead of waiting 10 s

### **Communication**

- Added network interface selection through `CYCLONEDDS_URI`

### **Flight Logs**

- Added an RC Input tab

### **Simulation**

- Added a suspended payload plugin

### **Other**

- Moved time-consuming operations such as transfers and builds to separate threads
- Added file output for long build error messages
- Rounded decimal values in YAML output to a reasonable precision
