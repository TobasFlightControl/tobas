# Release v2.10

## Changes

---

### State Estimation

- Sensors used by ESKF can now be selected in Setup Assistant
- External pose input can now be provided to ESKF
- Changed the takeoff and landing detection conditions

### Failsafe

- The ESC communication loss detection threshold can now be configured
- Once target thrust begins to be output, disarm after a 500 ms communication loss instead of waiting 10 s

### Communication

- The network interface can now be specified with `CYCLONEDDS_URI`

### Flight Logs

- Added an RC Input tab

### Simulation

- Added a suspended payload plugin

### Other

- Run time-consuming processes, such as transmission and builds, in separate threads
- Write long build error messages to a file
- Round decimal values in YAML to a reasonable precision
