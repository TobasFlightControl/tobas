# Release v2.16

## **Environment**

---

ROS 2 Jazzy

## **Changes**

---

### **Control**

- Extended the active-tilt multicopter controller to support configurations that include fixed rotors

### **Missions**

- Added a choice of stopping or passing through at waypoints (SPLINE_WAYPOINT)

### **Fail-Safe**

- Added RTL activation if communication with at least one ESC is lost

### **Communication**

- Added timestamps and sequence numbers to heartbeat messages

### **Ground Control Station**

- Changed the layout
- Added a dialog message when communication with the FC is unexpectedly lost

### **Flight Logs**

- Added automatic vertical axis scaling for each plot

### **Other**

- Added file output for XACRO parsing errors
- Allowed the flight core to run without a network connection
- Improved control latency and jitter
