## Changes

---

### Sensor Processing

- Added RPM filter support (FC201 and later)

### State Estimation

- Fusion of barometric and GNSS altitudes

### Control

- Mixing that accounts for motor and propeller efficiency (minimizes current while satisfying control commands)

### Missions

- Mission save and load functionality
- Altitude can now be specified as either relative to the takeoff point or above sea level

### Failsafe

- Disarm if the vehicle has not yet taken off
- Select the appropriate action based on position and velocity estimation accuracy

### Manual Mode

- Adjustable stick deadband
- Command feedforward acceleration in position control mode

### Ground Station

- Display altitude relative to the startup position and MSL altitude
- Display the number of satellites used for GNSS positioning

### Flight Logs

- Recall flight log name history using the up and down buttons
- Display download progress
- rosbag output support

### Boot Device Settings

- Read the current settings when connecting to a device
- Static IP configuration

### Other

- Include user package launch files within the vehicle namespace
- Prevent GNSS position initialization during flight
- Output the new value to the console when a dynamic parameter is changed
- Automatically expand the partition on first boot
- Change message QoS to prevent dropped messages
- Change the CPU used by the interface node: 3 -> 0
- Save motor RPM gains in the project folder
