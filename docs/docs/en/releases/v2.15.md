# Release v2.15

## **Environment**

---

ROS 2 Jazzy

## **Changes**

---

### **Sensor Processing**

- Added RPM filter support (FC201 and later)

### **State Estimation**

- Added fusion of barometric and GNSS altitude

### **Control**

- Added motor and propeller efficiency to mixing to minimize current while meeting control commands

### **Missions**

- Added mission saving and loading
- Added altitude specification above sea level as well as relative to the takeoff location

### **Fail-Safe**

- Added disarming before takeoff
- Added selection of an appropriate response based on position and velocity estimation accuracy

### **Manual Mode**

- Added adjustable stick deadbands
- Added feedforward acceleration commands in position control mode

### **Ground Control Station**

- Added display of altitude relative to the startup position and MSL altitude
- Added display of the number of satellites used for GNSS positioning

### **Flight Logs**

- Added up/down button navigation through flight log name history
- Added download progress display
- Added rosbag export

### **Boot Device Configuration**

- Added loading of current settings when connecting to a device
- Added static IP configuration

### **Other**

- Changed user package launch files to be included within the aircraft namespace
- Prevented GNSS position initialization during flight
- Added console output of new values when changing dynamic parameters
- Added automatic partition expansion on first boot
- Changed message QoS to prevent dropped messages
- Moved interface nodes from CPU3 to CPU0
- Added saving of motor speed control gains to the project folder
