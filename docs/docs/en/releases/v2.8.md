## Changes

---

### Sensor Processing

- Implemented WMM-based compass calibration for large aircraft

### Communication

- Implemented FC-to-GCS communication checking

### Ground Control Station

- Stabilized screen updates during Qt event processing
- Display a dialog when the GCS is disconnected from the network
- Changed the GCS power button behavior to shut down only the FC while leaving the GCS running

### Flight Logs

- Added user joint states

### Simulation

- Accounted for propeller inertial forces and gyroscopic effects
- Replaced the Gazebo joint controller from `ros2_controllers` with a custom plugin

### Other

- Changed the specifications of the user Python package
- Implemented an option to disable the built-in controller
- Build projects in a separate thread
- Changed the ROS 2 installation layout on the Raspberry Pi from `isolated` to `merged`
