# Release v2.8

## **Environment**

---

ROS 2 Jazzy

## **Changes**

---

### **Sensor Processing**

- Added WMM-based compass calibration for large aircraft

### **Communication**

- Added checking of communication from the FC to the GCS

### **Ground Control Station**

- Stabilized screen updates in Qt event processing
- Added a dialog when the GCS disconnects from the network
- Changed the GCS power button to shut down only the FC while keeping the GCS running

### **Flight Logs**

- Added user joint states

### **Simulation**

- Added propeller inertial forces and gyroscopic effects
- Replaced the Gazebo joint controller from `ros2_controllers` with a custom plugin

### **Other**

- Changed the user Python package specification
- Added an option to disable the built-in controller
- Moved project builds to a separate thread
- Changed the ROS 2 installation layout on the Raspberry Pi from `isolated` to `merged`
