# Release v2.13

## **Environment**

---

ROS 2 Jazzy

## **Changes**

---

### **Control**

- Removed controller output constraints
- Added translational control gain scaling based on target thrust
- Added anti-windup to the position controller
- Added feedforward acceleration to position commands
- Added smooth target attitude transitions when changing flight modes

### **Missions**

- Changed mission altitude to use the arming location as its reference instead of the startup location
- Added a smooth stop when a mission is overwritten or canceled

### **Manual Mode**

- Changed disarm commands to stop the motors immediately
- Prevented enabling manual mode while the kill switch is on
- Added rate limits to transmitter commands

### **Other**

- Changed the GPS icon
- Improved the GCS message viewer
- Fixed the network interface selection
- Moved ROS logs from storage to RAM
