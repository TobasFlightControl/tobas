## Changes

---

### Control

- Removed controller output constraints
- Throttled translational control gains based on target thrust
- Implemented anti-windup for the position controller
- Added feedforward acceleration to position commands
- Added smooth target attitude transitions when changing flight modes

### Missions

- Mission altitude is now relative to the arming location instead of the startup location
- Missions now stop smoothly before being overridden or canceled

### Manual Mode

- Motors now stop immediately upon receiving a disarm command
- Manual mode can no longer be enabled while the kill switch is engaged
- Limited the rate of change of commands from the RC transmitter

### Other

- Changed the GPS marker
- Improved the GCS message viewer
- Fixed the network interface
- ROS logs are now written to RAM instead of storage
