# リリース v2.15

## 変更点

---

### センサ処理

- RPMフィルタに対応 (FC201以降)

### 状態推定

- 気圧高度とGNSS高度のフュージョン

### 制御

- モータとプロペラの効率を考慮したミキシング（制御指令を満たしつつなるべく電流が小さくなるようにする）

### ミッション

- ミッションの保存・読込機能
- 高度を離陸地点からの相対値に加えて海抜で指定可能に

### フェイルセーフ

- 離陸前ならディスアーム
- 位置・速度の推定精度に応じて適切な動作を選択

### マニュアルモード

- スティックの遊びの範囲を調整可能に
- 位置制御モード時にフィードフォワード加速度を指令

### 地上基地局

- 起動位置からの相対高度とMSL高度を表示
- GNSS即位に使用している衛生数を表示

### 飛行ログ

- フライトログ名の履歴を上下ボタンで再現できるように
- ダウンロードの進捗を表示
- rosbag出力機能

### ブートデバイス設定

- デバイスとの接続時に現在の設定を読み込む
- 固定IP設定機能

### その他

- ユーザパッケージのlaunchファイルを機体の名前空間内でインクルード
- 飛行中にGNSS位置の初期化処理を行わないように
- 動的パラメータ変更時に変更先の値をコンソール出力
- 初回ブート時にパーティションを自動で拡張
- メッセージのQoSを変更して取りこぼしを防ぐ
- インターフェースノードの動作CPUを変更: 3 -> 0
- モータ回転数ゲインをプロジェクトフォルダに保存
