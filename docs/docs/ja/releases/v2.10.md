## 変更点

---

### 状態推定

- ESKF が使用するセンサを Setup Assistant で選択できるように
- ESKF に外部 Pose を入れられるように
- 離陸判定と着陸判定の条件を変更

### フェイルセーフ

- ESC 通信断絶判定の閾値を変更できるように
- 目標推力が出始めてからだと 10s 待たずに 500ms 断絶でディスアーム

### 通信

- `CYCLONEDDS_URI`でネットワークインターフェースを指定可能に

### 飛行ログ

- RC Input のタブを追加

### シミュレーション

- 吊り下げ荷物のプラグインを追加

### その他

- 送信やビルドなどの時間のかかる処理を別スレッドでやる
- ビルドエラーメッセージが長ければファイル出力
- YAML の小数出力を適度に丸める
