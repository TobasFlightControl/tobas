## 変更点

---

### センサ処理

- 大型機のための WMM を利用したコンパスキャリブレーションを実装

### 通信

- FC から GCS の通信確認機能を実装

### 地上基地局

- Qt イベント処理の画面更新を安定化
- GCS がネットワークから切断されたらダイアログを出す
- GCS の電源ボタンの挙動変更．GCS は残し FC のみ落とす．

### 飛行ログ

- ユーザジョイントの状態を追加

### シミュレーション

- プロペラの慣性力とジャイロ効果を反映
- Gazebo のジョイントコントローラを`ros2_controllers`から自作プラグインに変更

### その他

- ユーザ用 Python パッケージの仕様変更
- ビルトインの制御器を使用しないオプションを実装
- プロジェクトのビルドを別スレッドで行う
- ラズパイ側の ROS 2 インストールレイアウトを`isolated`から`merged`に変更
