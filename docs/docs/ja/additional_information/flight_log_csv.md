# 飛行ログの CSV 出力

`Flight Log`で出力する CSV の各列の意味，単位，座標系を説明します．
出力操作については，[飛行ログの CSV 出力手順](../getting_started/flight_test.md#flight-log-csv-export)を参照してください．

## 座標系と表記

| 座標系            | 原点・各軸の正方向                      |
| ----------------- | --------------------------------------- |
| グローバル（ENU） | 原点: 起動地点．X: 東，Y: 北，Z: 上．   |
| 機体（FLU）       | X: 機体前方，Y: 機体左方，Z: 機体上方． |

回転の正方向は，各軸に対して右ねじの方向です．

各列の単位は，表の「単位」列に記載しています．
以下の表の`{X,Y,Z}`は，X，Y，Z の 3 列をまとめた表記です．
例えば`Pose/{X,Y,Z}`は，`Pose/X`，`Pose/Y`，`Pose/Z`を表します．
`{Roll,Pitch,Yaw}`や磁気補正行列の成分も同様です．

## CSV の項目

### Time

| 列名   | 単位 | 意味                                                                               |
| ------ | ---- | ---------------------------------------------------------------------------------- |
| `Time` | s    | フィルタリング前の IMU メッセージ（`imu_raw`）の`header.stamp`を秒に換算した時刻． |

クロックソースと基準時刻は，実行環境によって次のように決まります．

| 環境             | クロックソース                             | 基準時刻・進み方                                                              |
| ---------------- | ------------------------------------------ | ----------------------------------------------------------------------------- |
| 実機             | FC の単調増加クロック（`RCL_STEADY_TIME`） | FC の OS 起動を基準に進む時刻．標準設定は`TOBAS_CLOCK_TYPE=steady_time`．     |
| シミュレーション | Gazebo のシミュレーション時刻（`simTime`） | シミュレーション開始を 0 s として，シミュレーションの進行に合わせて進む時刻． |

実機では，IMU ドライバーがサンプリング処理の開始時に読み取ったクロックの値を使います．
シミュレーションでは，IMU プラグインが取得した`simTime`を使います．
シミュレーションを一時停止すると，この時刻の進行も止まります．

CSV の行は`imu_raw`の時刻ごとに作られます．
各トピックについて，前の行の時刻より後，かつ現在の行の時刻以下にある最新のメッセージが使われます．
各項目のサンプリング時刻は，この区間内でトピックごとに決まります．

### Pose

| 列名                          | 単位 | 座標系     | 意味                                 |
| ----------------------------- | ---- | ---------- | ------------------------------------ |
| `Pose/{X,Y,Z}`                | m    | グローバル | 推定位置．                           |
| `Pose/{Roll,Pitch,Yaw}`       | deg  | グローバル | 推定したロール角，ピッチ角，ヨー角． |
| `TargetPose/{X,Y,Z}`          | m    | グローバル | 目標位置．                           |
| `TargetPose/{Roll,Pitch,Yaw}` | deg  | グローバル | 目標ロール角，ピッチ角，ヨー角．     |

姿勢角はグローバル座標系に対する機体の姿勢を表し，回転行列を`R = Rz(Yaw) Ry(Pitch) Rx(Roll)`とするロール・ピッチ・ヨー表現です．
Yaw = 0 deg が東，Yaw = +90 deg が北を向く姿勢に対応します．
CSV では Pitch が −90～+90 deg，Roll と Yaw が −180～+180 deg の範囲の主値になります．
Pitch が ±90 deg の特異姿勢では，変換処理は Roll をゼロに設定します．

ビューアは角度をアンラップし，±180 deg をまたぐ変化を連続した角度で表示します．
このため，CSV と表示値が 360 deg の整数倍だけ異なる場合があります．
制御器は，制御モードに応じた目標値を`TargetPose`に設定します．

### Twist

| 列名                                  | 単位  | 座標系 | 意味           |
| ------------------------------------- | ----- | ------ | -------------- |
| `Twist/LinearVelocity/{X,Y,Z}`        | m/s   | 機体   | 推定並進速度． |
| `Twist/AngularVelocity/{X,Y,Z}`       | rad/s | 機体   | 推定角速度．   |
| `TargetTwist/LinearVelocity/{X,Y,Z}`  | m/s   | 機体   | 目標並進速度． |
| `TargetTwist/AngularVelocity/{X,Y,Z}` | rad/s | 機体   | 目標角速度．   |

並進速度は，機体の前方・左方・上方の速度成分です．
角速度は，機体の X，Y，Z 軸まわりの回転速度です．
目標並進速度は，現在の推定姿勢を使って機体座標系で表します．

### Accel

| 列名                               | 単位   | 座標系 | 意味                         |
| ---------------------------------- | ------ | ------ | ---------------------------- |
| `Accel/LinearAccel/{X,Y,Z}`        | m/s²   | 機体   | 重力補正後の推定並進加速度． |
| `Accel/AngularAccel/{X,Y,Z}`       | rad/s² | 機体   | 推定角加速度．               |
| `TargetAccel/LinearAccel/{X,Y,Z}`  | m/s²   | 機体   | 目標並進加速度．             |
| `TargetAccel/AngularAccel/{X,Y,Z}` | rad/s² | 機体   | 目標角加速度．               |

並進加速度は，機体の運動による加速度を機体座標系で表した値です．
角加速度は，機体の各軸まわりの角速度の時間変化です．
目標並進加速度は，現在の推定姿勢を使って機体座標系で表します．

### IMU

| 列名                | 単位   | 座標系 | 意味                                                 |
| ------------------- | ------ | ------ | ---------------------------------------------------- |
| `IMU/Accel/{X,Y,Z}` | m/s²   | 機体   | フィルタリング前の加速度計の比力（specific force）． |
| `IMU/Gyro/{X,Y,Z}`  | rad/s  | 機体   | フィルタリング前のジャイロ角速度．                   |
| `IMU/DGyro/{X,Y,Z}` | rad/s² | 機体   | IMU 処理系から配信されたフィルタリング前の角加速度． |

CSV の IMU 列は，振動フィルタリング前の Raw 信号です．
加速度計の比力は重力補正前の信号であり，水平・静止状態では Z 成分が約 +g になります．

### MagneticField

| 列名                    | 単位   | 座標系 | 意味                 |
| ----------------------- | ------ | ------ | -------------------- |
| `MagneticField/{X,Y,Z}` | 無次元 | 機体   | 校正済みの磁気信号． |

標準の磁気処理系で，校正楕円体を単位球面に写像した無次元の磁気ベクトルです．

### GNSS

| 列名              | 単位 | 意味                          |
| ----------------- | ---- | ----------------------------- |
| `GNSS/Latitude`   | deg  | WGS 84 の測地緯度．北緯が正． |
| `GNSS/Longitude`  | deg  | WGS 84 の測地経度．東経が正． |
| `GNSS/HeightMSL`  | m    | 平均海面からの高さ．          |
| `GNSS/EastSpeed`  | m/s  | 東向きを正とする対地速度．    |
| `GNSS/NorthSpeed` | m/s  | 北向きを正とする対地速度．    |
| `GNSS/UpSpeed`    | m/s  | 上向きを正とする対地速度．    |

### RCInput

| 列名                 | 範囲・値                            | 意味                       |
| -------------------- | ----------------------------------- | -------------------------- |
| `RCInput/Roll`       | −1～+1                              | 正規化したロール入力．     |
| `RCInput/Pitch`      | −1～+1                              | 正規化したピッチ入力．     |
| `RCInput/Throttle`   | −1～+1                              | 正規化したスロットル入力． |
| `RCInput/Yaw`        | −1～+1                              | 正規化したヨー入力．       |
| `RCInput/FlightMode` | 0: Acrobat，1: Stabilize，2: Loiter | 飛行モードの選択．         |
| `RCInput/SubMode`    | 0: OFF，1: ON                       | サブモードスイッチ．       |
| `RCInput/Enable`     | 0: OFF，1: ON                       | 無線操縦の有効・無効．     |
| `RCInput/Kill`       | 0: OFF，1: ON                       | キルスイッチ．             |

Roll，Pitch，Throttle，Yaw は，RC 入力を −1～+1 に正規化した操作量です．

### Battery

| 列名              | 単位 | 意味             |
| ----------------- | ---- | ---------------- |
| `Battery/Voltage` | V    | バッテリー電圧． |
| `Battery/Current` | A    | バッテリー電流． |

### Engine

| 列名              | 単位 | 意味                                                  |
| ----------------- | ---- | ----------------------------------------------------- |
| `Engine/Throttle` | %    | エンジンのスロットル指令．指令の割合を 100 倍した値． |

### CPU

| 列名              | 単位 | 意味                                       |
| ----------------- | ---- | ------------------------------------------ |
| `CPU/Frequency`   | GHz  | CPU の動作周波数．Hz を 10⁹ で割って出力． |
| `CPU/Temperature` | °C   | CPU 温度．                                 |
| `CPU/Load`        | %    | CPU 負荷．負荷の割合を 100 倍した値．      |

### Rotor

| 列名                           | 単位・値                 | 意味                       |
| ------------------------------ | ------------------------ | -------------------------- |
| `Rotor/TargetRPM/<link_name>`  | rpm                      | ローター回転速度の指令値． |
| `Rotor/CurrentRPM/<link_name>` | rpm                      | ローター回転速度の計測値． |
| `Rotor/Link/<link_name>`       | 0: 通信異常，1: 通信正常 | ローターとの通信状態．     |

ローターの列は，記録されたリンク名ごとに作られます．
回転速度はメッセージの rad/s から rpm に変換されます．

### Latency

| 列名                     | 単位 | 意味             |
| ------------------------ | ---- | ---------------- |
| `Latency/ControlLatency` | µs   | 制御レイテンシ． |

出力側で計測した現在時刻と，受信した制御指令のヘッダー時刻との差です．

### VibrationLevel

| 列名                     | 単位 | 座標系 | 意味                             |
| ------------------------ | ---- | ------ | -------------------------------- |
| `VibrationLevel/{X,Y,Z}` | m/s² | 機体   | 加速度の振動レベル（近似 RMS）． |

Raw 加速度をハイパスフィルタに通して二乗し，ローパスフィルタで平滑化した後に平方根を取った値です．

### AdditionalAccel

| 列名                      | 単位 | 座標系     | 意味                               |
| ------------------------- | ---- | ---------- | ---------------------------------- |
| `AdditionalAccel/{X,Y,Z}` | m/s² | グローバル | 外部から与えられた追加並進加速度． |

### DisturbanceForce

| 列名                              | 単位 | 座標系     | 意味                         |
| --------------------------------- | ---- | ---------- | ---------------------------- |
| `DisturbanceForce/Force/{X,Y,Z}`  | N    | グローバル | 推定外乱力．                 |
| `DisturbanceForce/Torque/{X,Y,Z}` | N·m  | 機体       | 重心まわりの推定外乱トルク． |

### Observer

| 列名                                           | 単位   | 座標系 | 意味                                             |
| ---------------------------------------------- | ------ | ------ | ------------------------------------------------ |
| `Observer/AccelBias/{X,Y,Z}`                   | m/s²   | 機体   | 推定加速度計バイアス．                           |
| `Observer/GyroBias/{X,Y,Z}`                    | rad/s  | 機体   | 推定ジャイロバイアス．                           |
| `Observer/MagHardIronBias/{X,Y,Z}`             | 無次元 | 機体   | 校正済み磁気信号に対する推定ハードアイアン補正． |
| `Observer/MagSoftIronBias/{XX,YY,ZZ,XY,YZ,ZX}` | 無次元 | 機体   | 推定ソフトアイアン補正行列の成分．               |
| `Observer/BarometerAltitudeBias`               | m      | —      | 推定気圧高度バイアス．                           |
| `Observer/Gravity`                             | m/s²   | —      | 推定した重力加速度の大きさ．                     |
| `Observer/GNSSAnomalyScore`                    | —      | —      | GNSS 観測の異常度を示す推定器の診断値．          |

磁気のソフトアイアン補正は対称行列の 6 成分を，XX，YY，ZZ，XY，YZ，ZX の順で出力します．

### MultirotorController

| 列名                                                  | 単位  | 座標系               | 意味                     |
| ----------------------------------------------------- | ----- | -------------------- | ------------------------ |
| `MultirotorController/IntegralError/{X,Y,Z}`          | m·s   | グローバル           | 位置追従誤差の積分状態． |
| `MultirotorController/IntegralError/{Roll,Pitch,Yaw}` | rad·s | 制御器の姿勢誤差成分 | 姿勢追従誤差の積分状態． |

位置と姿勢の誤差積分値は，制御器の制限・リセット処理が適用された内部状態です．
姿勢誤差には，制御器に応じてオイラー角の誤差や回転ベクトルの誤差が使われます．
