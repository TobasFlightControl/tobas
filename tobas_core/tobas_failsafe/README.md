# Tobas Fail-Safe

## 共通仕様

### フェイルセーフの動作の流れ

- 離陸前にフェイルセーフが発動したらディスアーム．
- フェイルセーフの流れは統一で，必ず最後はディスアーム: RTL -> Land -> Disarm

### フェイルセーフを発動しない条件

1. 手動操縦中
2. 位置と速度の推定精度が低い場合

## 動作

### RTL (Return to Launch)

最低高度まで上昇後にアームされた地点まで戻り，着陸してディスアームする．

### Land

その場で着陸してディスアームする．

### Disarm

全てのモータを即座に停止する．

## チェック項目

### バッテリーフェイルセーフ

#### 発動条件

バッテリー電圧が閾値を下回った状態が一定時間続く．

#### 動作

Land

#### 回復

なし

### ラジオフェイルセーフ

#### 発動条件

レシーバからの S.BUS が一定時間途絶える．

#### 動作

- 位置推定できている場合 -> RTL
- 位置推定できていない場合 -> Land

#### 回復

再び S.BUS が確認されたら手動操縦を再開．
