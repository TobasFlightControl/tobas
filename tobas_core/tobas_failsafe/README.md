# Tobas Fail-Safe

## 共通仕様

- 離陸前にフェイルセーフが発動したらディスアーム．
- フェイルセーフの流れは統一で，必ず最後はディスアーム: RTL -> Land -> Disarm

## 動作

### RTL (Return to Launch)

発動した時の高度を保ったままアームされた地点まで戻る．
GNSS 位置が取得できていなければスキップされる．

### Land

その場で着陸する．

### Disarm

全てのモータを即座に停止する．

## チェック項目

### バッテリーフェイルセーフ

#### 発動条件

バッテリー電圧が閾値を下回った状態が一定時間続く．

#### 動作

Land

#### 回復

なし

### ラジオフェイルセーフ

#### 発動条件

レシーバからの S.BUS が一定時間途絶える．

#### 動作

RTL

#### 回復

再び S.BUS が確認されたら手動操縦を再開．
